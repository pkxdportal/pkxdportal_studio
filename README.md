# PK XD PORTAL — объединённый сайт

В одном проекте сохранены четыре раздела:
- Посты и новости, включая поиск, категории, закреплённые публикации и отдельные страницы постов.
- Студия правил.
- Конструктор сундуков.
- Редактор аватарок.

## Структура
- `index.html` — главная страница со всеми четырьмя разделами и лентой постов.
- `studio.html` — три редактора из первого сайта. Прямые ссылки: `studio.html#rules`, `studio.html#chests`, `studio.html#avatars`.
- `posts/` — отдельные HTML-страницы постов.
- `posts.json` — данные ленты.
- `assets/` — изображения для постов и дизайна.
- `style.css` — стиль главной страницы и ленты.
- `src/index.js`, `wrangler.jsonc` — исходный Cloudflare Worker авторизации из второго сайта.

## Публикация
Это статический сайт. Загружай все файлы и папки ZIP в корень репозитория `pkxdportal/pkxdportal_studio` для GitHub Pages.
Сохраняй относительные пути и папки. При размещении по текущему адресу `https://pkxdportal.github.io/pkxdportal_studio/` путь OAuth Worker и работа с GitHub API сохраняют исходные настройки.

Важно: вход владельца использует внешний Cloudflare Worker `https://pkxd-auth.turborussnezkiy.workers.dev/login` и исходный репозиторий `pkxdportal/pkxdportal_studio`. Если сайт переедет на другой адрес или в другой репозиторий, нужно изменить адрес обратного перехода в Worker и настройки репозитория в `index.html`. Сам код авторизации не менялся.

## Локальный просмотр
Используй локальный HTTP-сервер, иначе браузер может блокировать загрузку `posts.json` при открытии `file://`.

```bash
python -m http.server 8000
```

Открой `http://localhost:8000/`.

## Ограничение
Кнопка «Нравится» на страницах постов использует `localStorage` браузера. Это локальный счётчик, а не общая серверная статистика. Так было и в исходном сайте.


## Доступ к редакторам
Главная страница скрывает инструменты от обычных посетителей. URL studio.html проверяет состояние входа перед перенаправлением на studio-app.html. Поскольку репозиторий публичный и размещён как статический сайт, это ограничение интерфейса, а не серверный запрет на чтение исходников. Внешний OAuth Worker пока возвращает владельца на прежнюю GitHub Pages страницу, поэтому вход открывается отдельным окном и использует общий localStorage хоста pkxdportal.github.io. Для нового домена требуется обновление Worker.
